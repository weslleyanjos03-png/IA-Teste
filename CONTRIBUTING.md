# Como contribuir com o Kanban Flow

Obrigado pelo interesse em contribuir! Sugestões, relatos de erros e melhorias são bem-vindos em português ou inglês.

## Antes de começar

1. Confira as [issues existentes](https://github.com/weslleyanjos03-png/kanban-flow/issues) para evitar solicitações duplicadas.
2. Para mudanças maiores, abra uma issue descrevendo a proposta antes de programar.
3. Faça um fork, crie uma branch descritiva e envie um Pull Request para `main`.
4. Explique no Pull Request o objetivo, as alterações e como verificou o resultado.

## Desenvolvimento

- O aplicativo roda diretamente no navegador pelo arquivo `index.html`.
- Teste o comportamento no computador e no celular, principalmente filtros, movimento de tarefas e importação/exportação de JSON.
- Mantenha a compatibilidade com GitHub Pages: não exija servidor nem serviços pagos para usar a versão gratuita.
- Prefira alterações pequenas e claras. Se incluir dependências, explique por que são necessárias.

## Privacidade e segurança

**Nunca inclua dados reais de clientes ou informações pessoais em commits, issues, capturas de tela, arquivos JSON ou Pull Requests.** Use dados fictícios.

Não exponha vulnerabilidades exploráveis publicamente. Leia [SECURITY.md](SECURITY.md) antes de relatá-las.

## Convivência

Respeite as outras pessoas, apresente críticas de forma construtiva e mantenha discussões técnicas focadas em melhorias do projeto.
