# Kanban Flow 🚀

**A free, responsive Kanban board for tasks, leads, proposals, delivery and support — with no account or backend required.**

[🚀 Live app](https://weslleyanjos03-png.github.io/IA-Teste/) · [🇧🇷 Portuguese README](README.md) · [⭐ Star on GitHub](https://github.com/weslleyanjos03-png/IA-Teste)

</div>

## Features

- Five stages: First Contact, Proposal, In Production, Delivery and Support.
- Create, edit, complete, move and delete task cards.
- Drag cards on desktop; use the stage selector on mobile.
- Search tasks and filter by category or completion status.
- Add links to task cards and start a WhatsApp share action.
- Import and export task data in JSON format.
- Responsive layout for phones, tablets and computers.

## Try it

Use the [live Kanban Flow demo](https://weslleyanjos03-png.github.io/IA-Teste/), or clone the project and open the HTML file in a modern web browser:

```bash
git clone https://github.com/weslleyanjos03-png/IA-Teste.git
cd IA-Teste
```

Then open `index.html`. You don't need a build command, a server, an account or a paid service.

## Data and privacy

The public source code contains no real customer records. A fresh board starts empty. Your tasks are stored in the current browser's local storage, not in a remote database, and do not sync across devices.

**Local storage and JSON exports are not encrypted.** Clearing browser data may erase tasks, so keep your own backups. Avoid putting sensitive personal information in cards or shared messages.
